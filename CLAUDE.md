# Instruções para o Claude

## Registro de alterações

Sempre que realizar qualquer melhoria, correção ou ajuste no projeto, **atualize o arquivo `CHANGELOG.md`** na raiz do repositório, adicionando uma nova entrada no topo do histórico (abaixo do cabeçalho) com:

- **Data** no formato `[AAAA-MM-DD]`
- **Título** breve da alteração
- **Arquivo(s) alterado(s)**
- **Descrição** concisa do que foi feito e por quê

## GitHub CLI

Sempre utilizar o `gh` CLI para operações Git e GitHub (autenticação, push, pull, PRs, issues, etc.).
